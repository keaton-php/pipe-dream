# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please **do not** report a security problem in a public issue, discussion or pull request.

Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. If you cannot use that, email kevin@kevineaton.dev with the subject line `SECURITY: pipe-dream`.

Please include:

- the version of the package, PHP and (where it applies) Laravel you are running;
- what the problem is and what an attacker could do with it;
- the smallest code that reproduces it.

You will get a reply within a few days. A confirmed problem is fixed in a patch release, and you are credited in the changelog unless you would rather not be.
