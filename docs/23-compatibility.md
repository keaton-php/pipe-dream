# Compatibility, changelog and license

Which versions does Pipe Dream support, and where is its history?

## Compatibility

Tested on Laravel 9 to 13 (CI matrix), with each Laravel major on the PHP versions it supports:

| Laravel | PHP |
|---|---|
| 9 | 8.1 – 8.2 |
| 10 | 8.1 – 8.3 |
| 11 | 8.2 – 8.4 |
| 12 | 8.2 – 8.5 |
| 13 | 8.3 – 8.5 |
